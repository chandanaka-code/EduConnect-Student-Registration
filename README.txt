EDUCONNECT - STUDENT REGISTRATION SYSTEM

FILES
- index.php: registration form
- style.css: responsive design and styling
- script.js: jQuery form validation
- submit.php: PHP validation and result display

RUN LOCALLY USING XAMPP
1. Install and open XAMPP.
2. Copy the student_registration_system folder into C:\xampp\htdocs\
3. Start Apache from the XAMPP Control Panel.
4. Open http://localhost/student_registration_system/ in your browser.
5. Fill the form and click Submit Application.

The form validates using jQuery in the browser and PHP on the server.
This assignment demo displays submitted information; it does not save it to a database.
jQuery and Google Fonts use online CDNs.
